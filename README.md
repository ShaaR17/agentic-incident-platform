# Agentic AI Incident Resolution Platform

An Agentic AI platform that autonomously investigates IT production incidents using:

- Agentic AI
- RAG
- MCP
- Vector Database
- Logs
- Metrics
- Historical Incidents
- Runbooks
- Automated Remediation

## Goal

Investigate production incidents, identify probable root causes, recommend remediation actions, execute approved actions, and verify incident recovery.
